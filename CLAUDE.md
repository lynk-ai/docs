# Lynk docs
This is the docs repository of getlynk.ai
These docs are hosted on gitbook for humans to read, but most of the consumption of these docs is by AI agents either by cloning this repository or reading them from the website docs.getlynk.ai

## Best Practices
- Be critical about user requests, ask clarification questions if needed and act based on user answers and input.
- Plan before executing and share the plan with the user in an interactive way. always make changes step by step with the user
